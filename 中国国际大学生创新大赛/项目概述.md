# 电脉智勘-基于多模态大模型的变压器状态云边协同诊断系统
## Part ① 基于深度学习的变压器多模态边端故障诊断系统
- YOLOv7-SRSA 目标检测框架改进
- ADPR指针仪表数值异常检测
- 模型压缩：剪枝 / 量化 / 知识蒸馏，推理延迟<50ms
- 多源同步采集与时序对齐（TSN / 5G），变压器油温、局放、声学波形与图像流同帧融合
## Part ② 基于生成式增强的变压器异常图像数据与鲁棒检测模型研究
- Stable Diffusion + LoRA + SAM
- WTConv + Histogram Self-Attention改进 RT-DETR（WHRT-DETR）
- Curriculum-Domain Randomization：雾、雨、夜间、眩光等场景级随机化提升泛化
- 开集检测 & 不确定性估计：Energy-based + Monte-Dropout，标记潜在新故障
## Part ③ 基于多模态大模型的变压器智能评估与决策系统
- Qwen 2.5-VL / InternVL 大模型 LoRA 微调，注入行业异常特征
- Retrieval-Augmented Generation (RAG)
- Self-Extend：上下文窗口扩展
- MCP 协议 AI Agent：自动调用巡检/报警/日志三大工具链
- 云-边编排：MQTT + Kafka 事件流，支持 OTA 迭代与多省部署。
# 协同逻辑
1. 数据闭环：② 生成/标注的数据持续刷新① 的轻量模型及③ 的多模态大模型。
2. 推理闭环：① 上传特征向量与初诊结果 → ③ 结合知识库给出最终评估并下发检修策略。
3. 迭代闭环：③ 反馈易错场景 → ② 定向合成难例 → ①/② 模型再训练升级。
